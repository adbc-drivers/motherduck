## ADBC Driver for MotherDuck v0.1.0-alpha.1

First (alpha) release of an [ADBC](https://arrow.apache.org/adbc/) driver for
[MotherDuck](https://motherduck.com). It connects through MotherDuck's
PostgreSQL protocol endpoint and is forked from Apache Arrow ADBC's libpq-based
PostgreSQL driver.

> [!WARNING]
> This is a pre-release. Options, behavior, and the driver's feature set may
> change before v0.1.0, and it needs `dbc install motherduck --pre` to install.
> Please report problems at
> [adbc-drivers/motherduck/issues](https://github.com/adbc-drivers/motherduck/issues).

> [!IMPORTANT]
> This is a separate driver, not a drop-in replacement for the ADBC PostgreSQL
> driver. It only works with MotherDuck, loads as `motherduck`, and some
> PostgreSQL driver options and features behave differently or aren't
> supported (for example bulk ingest and COPY result reads). See
> [Differences from the PostgreSQL driver](https://github.com/adbc-drivers/motherduck#differences-from-the-postgresql-driver).

### Highlights

- **`motherduck://` URIs and `motherduck.*` options (breaking).** The driver
  takes only `motherduck://` URIs (for example `motherduck:///my_db`), plus the
  short forms `md://` and DuckDB's `md:database`. `postgresql://`, `postgres://`
  and libpq keyword/value strings are rejected with `INVALID_ARGUMENT`. Every
  MotherDuck option is named `motherduck.*` (no `adbc.` prefix), and the URI's
  query takes them by name, such as `?motherduck.region=us-east-1`. Other query
  parameters, including libpq's (`sslmode`, `sslrootcert`, `options`, ...), are
  rejected. PostgreSQL settings aren't supported and may stop working in a
  future version.
- **Verified TLS by default.** Connections use `sslmode=verify-full`. The driver
  finds trusted root certificates itself (an explicit root file, `SSL_CERT_FILE`,
  the Linux CA bundle, or the macOS/Windows trust store) and fails to connect
  rather than falling back to an unverified connection. Set
  `motherduck.tls_root_cert_path` for a custom CA bundle, or
  `motherduck.tls_verify=false` to encrypt without verifying. Minimal container
  images with no CA certificates need one of these.
- **MotherDuck connection options.** The MotherDuck token is the password
  (`MOTHERDUCK_TOKEN`, the `password` option, or `motherduck.token`).
  `motherduck.region` sets the host, `motherduck.attach_mode` (`single` by
  default, or `workspace`), `motherduck.session_name` and `motherduck.db_schema`
  configure the session, and `motherduck.application_name` and
  `motherduck.connect_timeout` set the application name and connection timeout.
- **Streaming results.** Non-COPY query results are returned in batches rather
  than materialized up front.
- **Accurate row counts.** The driver requests PostgreSQL command tags from
  MotherDuck, so `rows_affected` for `UPDATE` and `DELETE` is the number of rows
  changed, and DML/DDL return an empty stream.
- **Safer errors.** `CREATE SECRET` statements are masked in error messages and
  DuckDB's statement echo is stripped from error text.
- **Metadata that works on MotherDuck.** `GetObjects`, `GetTableSchema`, and the
  `GetInfo` vendor name are adapted to MotherDuck.

### Platforms

linux amd64/arm64, macOS arm64, windows amd64.

### Install

```sh
dbc install motherduck --pre
```

or build from source; see the
[README](https://github.com/adbc-drivers/motherduck#building).

## New Features

- feat!: require motherduck://, md:// or md: URIs, rename options to motherduck.*, add application_name and connect_timeout (#93)
- feat: verify the server's certificate by default (#54)
- feat: add motherduck.db_schema and qualify the current schema (#79)
- feat: stream non-COPY query results in batches (#63)
- feat: request Postgres command tags from MotherDuck (#70)
- feat: add motherduck.session_name and motherduck.token options (#36)
- feat: add motherduck.attach_mode, defaulting to single (#24)
- feat: report MotherDuck driver name and version
